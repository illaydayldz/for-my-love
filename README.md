# For My Love - Acil Durum Butonu

Sevgilin için pixel art tarzında mini motivasyon sitesi.

## GitHub Pages'e yükleme
1. GitHub'da yeni repo oluştur.
2. Bu zip içindeki dosyaları repo ana dizinine yükle.
3. Settings > Pages bölümüne gir.
4. Source olarak `Deploy from a branch` seç.
5. Branch: `main`, Folder: `/root` seçip Save yap.
6. Birkaç dakika sonra site linki oluşur.

## Düzenleme
- Notları değiştirmek için `script.js` içindeki `notes` listesini düzenle.
- Görseli değiştirmek için `assets/pixel-preview.png` dosyasını aynı isimle değiştir.
- Renkleri değiştirmek için `style.css` içinde `:root` kısmını düzenle.
